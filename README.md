# T-case
this is my personal laptop bag, made to look like a briefcase for a professional and sleek look.

# Features
- 3d printed parts
- two locks with key
- simple hinges
- engraved "-T- CASE" in the front

# CAD model
the structure is held together by two hinges on the back that are then blocked by 6 M5x15 bolts neach.

# BOM
this simple project uses:
1) 12x M5x15 bolt
2) 12x M3x15 bolt
3) 1x 3d printed bottom case
4) 1x 3d printed top case
5) 1x handle (https://tinyurl.com/nmxc99fe)
6) 2x locks (https://tinyurl.com/4hm3fa5m)
7) 2x hinges (https://tinyurl.com/e5sa7j9r)
