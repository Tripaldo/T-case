# T-case
this is my personal laptop bag, made to look like a briefcase for a professional and sleek look.

# Features
- 3d printed parts
- two locks with key
- simple hinges
- engraved "-T- CASE" in the front
- EVA foam carved to perfectly fit any computer and their respective charger

# CAD model
the structure is held together by two hinges on the back that are then blocked by 4 M5x15 bolts each.

# BOM
this simple project uses:
1) 12x bolt (I don't know the size)
2) 4x M3x15 bolt
3) 1x 3d printed bottom case
4) 1x 3d printed top case
5) 1x handle (https://tinyurl.com/3n6ac4hk)
6) 1x 2pcs locks (https://tinyurl.com/4hm3fa5m)
7) 1x 2pcs hinges (https://tinyurl.com/3tdeerkt)
8) 1x block of EVA foam (custom alibaba order)
